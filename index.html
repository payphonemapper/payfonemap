About This Migration

You have been redirected here because the PayFoneMap statistics have found a new home.

What is Fonectrix?

Fonectrix is a specialized, mobile-friendly product designed specifically to handle the statistical and analytical side of the PayFoneMap project. As the database grew, we recognized the need for a dedicated, responsive interface where users could quickly view global metrics, regional counts, and system-wide data without the overhead of the full mapping suite.

What is changing?

  • The Stats Page Only: Only the statistical reporting previously hosted at stats.payfonemap.com has been replaced.
  • Mobile Accessibility: Fonectrix is built to be lightweight, making it easier to check project growth and data distribution from any device.

What is staying the same?

  • PayFoneMap remains the parent project and the primary hub for the global directory. No changes are being made to the main PayFoneMap website.
  • All mapping features, community contributions, and the core directory will continue to operate exactly as they always have.
